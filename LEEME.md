# WEB2 · Prototipo street

Esta carpeta contiene una segunda propuesta visual de la web, con estética urbana de barber club neoyorquino. No reemplaza la web actual.

## Archivos

- `index.html`: la página del prototipo.
- `street.css`: estilos responsive.
- `street.js`: filtros del formulario, horas disponibles, reservas y acceso privado a la agenda.

El prototipo reutiliza las fotos y las rutas de API de la aplicación que están en la carpeta principal. Para verlo en Render, conserva `WEB2` como subcarpeta al subirlo al mismo repositorio y espera a que termine el despliegue. Después abre `https://TU-SERVICIO.onrender.com/WEB2/index.html`.
